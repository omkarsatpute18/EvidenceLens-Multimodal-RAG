# Demo video production guide

There is currently no recorded video file in this repository. `docs/demo-script.md` is the approved two-to-three-minute script; this guide turns it into a recordable submission asset.

## Recommended recording flow

Use OBS Studio, Loom, or another screen recorder. Record the browser window and a small terminal/status panel only when useful. Do not show `.env`, API keys, private files, or personal browser tabs.

1. Start EvidenceLens and open the local or deployed URL.
2. Show the title and one-sentence value proposition.
3. Upload all files from `examples/demo_bundle/`.
4. Show the processed file list and modality badges.
5. Ask: “Which region had the largest decline, what evidence supports this conclusion, and does the chart agree with the table?”
6. Show the answer, confidence, workflow timeline, retrieval trace, contradiction/limitation panels, and evidence cards.
7. Open the table evidence and chart preview.
8. Ask a follow-up question such as “What information is missing?”
9. End on the architecture/value proposition and the OmniRush disclosure.

## Timing target

Follow the timestamps in `docs/demo-script.md`: problem (0:00–0:20), solution (0:20–0:40), architecture (0:40–1:00), live demo (1:00–2:20), innovation and OmniRush (2:20–2:50).

## Finalization

Export MP4 at 1080p when practical, watch the full export once, and upload it to the submission platform or an authorized public/unlisted video host. Add the final URL to the submission form and `docs/submission-checklist.md`; do not invent a URL in the repository before uploading.
